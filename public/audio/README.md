# Músicas de fundo (royalty-free)

Coloque aqui os arquivos MP3. O app usa automaticamente se existirem;
senão continua com a música sintética (Web Audio).

## Arquivos esperados

| Arquivo | Uso |
|---------|-----|
| `quiz-bg.mp3` | Modo Quiz (solo) — loop |
| `live-01.mp3` … `live-10.mp3` | Modo Ao Vivo (uma por pergunta) |

Formato: **MP3**, idealmente loop contínuo, 128–192 kbps, volume moderado.

## Onde baixar (sem copyright / royalty-free)

### Gratuitas (boas para o projeto)
1. **[Pixabay Music](https://pixabay.com/music/)** — uso comercial gratuito, sem atribuição obrigatória
2. **[Mixkit](https://mixkit.co/free-stock-music/)** — gratuita para projetos
3. **[OpenGameArt](https://opengameart.org/)** — filtre por CC0 / CC-BY
4. **[Free Music Archive](https://freemusicarchive.org/)** — verifique a licença de cada faixa
5. **[YouTube Audio Library](https://studio.youtube.com/channel/UC/music)** — se tiver conta YouTube

Busque termos como: `kids upbeat`, `happy game`, `cartoon fun`, `family quiz`, `playful loop`.

### Artlist ([artlist.io](https://artlist.io/))
O Artlist **não é “sem copyright”**: as faixas têm copyright, mas com **assinatura paga** você recebe licença **royalty-free** (pode usar no site/app sem pagar por trilha).  
Os [video templates](https://artlist.io/video-templates) são templates de vídeo; para música use a seção **Music** do Artlist.

## Dicas
- Prefira instrumentais alegres e curtos (1–2 min) em loop
- Evite vocal com letra (distrai no quiz)
- Normalize o volume entre as faixas para não “pular” no Ao Vivo
- Não use músicas de streaming (Spotify, YouTube Music, etc.) sem licença
